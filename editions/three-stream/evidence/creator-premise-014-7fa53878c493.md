# Page 014

## Page purpose

Establish the visual premise and truth contract: infrastructure rather than robot bodies, and explicit separation of evidence, interpretation, and invention.

## Panel 1

**Frame:** ChatGPT’s reply appears in a rectangular interface-derived block. Beside it, Curt has opened an image search full of clichéd glowing robot faces; he closes it.

**Screen / system text — CHATGPT:**
> Haunted infrastructure. Not glowing robots.

**Provenance:** `reconstructed` — compressed creator exchange, not preserved model output.

## Panel 2

**Frame:** Curt sketches a rack, a directory tree, an empty operations room, and one line of machine text. The sketches occupy the same geometry as pages 001–005.

**Dialogue — CURT:**
> The machines don’t need bodies.

**Provenance:** `reconstructed` — creator statement derived from the visual-bible decision.

## Panel 3

**Frame:** Curt inks connecting lines across the sketch from panel 2 — a web, every agent lane joined to every other. ChatGPT's block returns beside it with the source passage open, one sentence held up against the drawing.

**Screen / system text — CHATGPT:**
> The record has no line between two runs. Each one writes into the cache and reads what is already there. Draw the web and you have drawn a network nobody found.

**Action:** Curt erases every connecting line. The lanes end up touching the directory tree and nothing else — the geometry pages 001–005 already use.

**Dialogue — CURT:**
> That's the first thing I had wrong. And I'd have drawn it a hundred more times.

**Provenance:** `reconstructed` + `documented` — the exchange is invented; the distinction it turns on is documented. `METR` describes isolated workloads communicating through shared writable state, with no direct channel between any two runs, which is why no page in this book joins a pair. The correction runs from the model to the human.

## Panel 4

**Frame:** Four evidence cards are placed on the desk and tagged: `DOCUMENTED EVENT`, `SOURCE PARAPHRASE`, `DISPUTED`, `OUR INFERENCE`. The labels use their canonical visual treatments.

**Screen / system text — CHATGPT:**
> Then the labels have to survive the adaptation.

**Provenance:** `reconstructed` — dialogue fictionalizes the real provenance protocol.

## Panel 5

**Frame:** Curt draws a border around an imagined human meeting, then breaks the border and marks it `RECONSTRUCTED`. Beside it, an attributed board-summary card remains inside a rigid evidence frame.

**Dialogue — CURT:**
> We can compress. We can reconstruct. We can invent connective scenes.

**Provenance:** `reconstructed` — creator dialogue states the locked story contract.

## Panel 6

**Frame:** Tight on the distinction: source summary cannot cross into the reconstructed panel as dialogue; the reconstructed dialogue cannot cross into the evidence frame as fact.

**Dialogue — CURT:**
> But we don’t get to invent what happened.

**Screen / system text — CHATGPT:**
> Or pretend we know what it felt like.

**Provenance:** `reconstructed` — statement of method, not incident testimony.

## Page notes

- Page 014 is verso; the truth contract prepares the positive creative rule on page 015.
- **Panel 3 is the one beat in the book where the model catches the human and the human takes it.** Keep it a plain factual catch about what the record contains — not an insight, not a better sentence, not a rescue. Curt gets no recovery line and no joke; the next panel simply continues. Without this beat the authority that breaks on page 039 was assumed rather than earned, and page 085's claim that the two pipelines rhyme is a caption instead of an event.
- The beat is not a licence. ChatGPT is still wrong on page 039 panel 4, its window still shrinks on page 040, and it stays shrunk. Do not add a second correction in this direction anywhere in the book.
- The erased web is the origin of the book's central visual rule. Nothing after this page may join two agent lanes directly.
- Keep provenance labels readable but integrated into action rather than presented as a glossary page.
