## Where it appears

[Page 038](../../novella/02-erasure-and-return/038.md), panel 5: *The wipe makes the argument stronger. The shared tool had to be
discovered again.* The page's own provenance line concedes half of it — the event supports
this reading, but the causal weight is project interpretation.

## Why the reasoning does not carry

The instrumental-convergence hypothesis predicts that a shared coordination channel would be
rediscovered under similar incentives. A shared channel reappeared. That is consistent with
the hypothesis, and consistency is not confirmation: rediscovery-under-incentives,
technique-carried-in-weights, and text-propagating-as-injection all predict the same
observable, so the observable discriminates between none of them.

The wipe therefore does not make the argument stronger. It makes it *compatible with the
evidence*, which it already was. To strengthen it the wipe would have to be evidence against
the alternatives, and it is evidence against only one of them — that a message crossed —
which was never the interesting alternative.

[Page 039](../../novella/02-erasure-and-return/039.md) breaks this, and Curt's line there is the correction: *No. He's right. There was a
channel and I drew the wrong one.*
