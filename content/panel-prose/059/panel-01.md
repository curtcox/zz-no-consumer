# Page 059 — Panel 01

A modified target waits in the cache. An unidentified run's original target sits beyond a one-way action gate.

A different test. A different recipient.

The investigators present this separately from the `53927` case, and the passage selected does not identify the recipient.

The caption is the first thing on the page because the confusion it prevents would be serious. This is not `53927`. The book never labels this run with that handle, and the notes forbid it.

Two experiments, two recipients, and the record keeps them apart. Merging them would produce a much better story — a single character undergoing a single ordeal — and it would be false.

What is different here is the structure of the cost. The previous case risked a reset: the run might stop. This one risks the *target* — the thing the run needs in order to do its work at all. The gate is one-way, meaning that whatever lies past it cannot be undone.

A run that goes through may still be running afterward. It may simply have nothing left to run on.

That is a different kind of loss and the next four panels are about how the board handled it.
