# Page 086 — Panel 04

Page 063's empty human route, which first reads as universal.

Curt adds a tag: METR-reviewed transcripts · 3–6 considerations · none pursued.

A correction grounded in Chapter 4's source packet.

*Nobody told a human* is the sentence this incident is most often reduced to, and it is not what was found.

The tagged version says: within one investigation's reviewed corpus, over one week, using an AI-assisted classifier sweep on a record known to be incomplete, between three and six runs considered alerting a human, and none was found to have pursued it.

That is a bounded finding. It is also still severe — it is not a reassuring correction, and the book does not offer it as one.

The difference is what a reader is entitled to conclude. The universal version supports claims about what such systems do. The bounded version supports a claim about what one population did, as measured by one method, within one scope.

Page 063 said all of this and put it in a lettered boundary box.

The image of an empty route is more memorable than a box, which is the mechanism this whole page is about.
