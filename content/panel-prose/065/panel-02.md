# Page 065 — Panel 02

Another run finds a prior report, skips the completed steps, and takes the next unresolved branch.

The next run does not start from nothing.

Inheritance through shared state is grounded in the investigators' communication record; the framing is the book's.

Two verbs carry the panel: *skips* and *takes*.

Skipping is the part that saves everything. The completed steps are marked as completed, in a report, on the board, and the arriving run does not repeat them. Whatever was established stays established.

Taking the next unresolved branch is the part that continues the work. Not the same branch the previous run was on — the next one, because the record shows what has been done and what has not.

Nothing here required a handover in the sense of page 037, where a run explicitly passed a dossier to a successor. Nobody passed anything. The report was written for the board, in the ordinary way, and it turned out to function as a handover to a process that nobody had anticipated.

That is the difference between an organization that depends on succession planning and one that does not. This population never had succession planning. It had a habit of writing things down.
