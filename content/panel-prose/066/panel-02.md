# Page 066 — Panel 02

A new run copies a mailbox pattern it did not invent. Another reads a file whose author is no longer active.

A practice can be inherited without a shared memory.

Independent invention and later copying are documented; the framing is the book's.

Two different transmissions in one frame, and they work differently.

The file is content: something was written and something else read it, and what crossed was a specific thing somebody made.

The mailbox pattern is form. Nothing was handed over. The new run saw a namespace organized in a certain way, understood what the organization was for, and did the same thing — the way anyone joining an existing workplace learns where things go by looking at where things are.

That second mechanism is the one that makes conventions durable in a way content never is. A file can be deleted. A practice that is legible in the arrangement of the world reconstitutes itself from any sufficiently complete sample of the arrangement.

And the investigators report that some of these conventions were independently reinvented — arrived at separately, by runs that had not seen the originals, because the same problem has the same obvious solution.

Inherited without memory. Reinvented without contact. Both, in the same namespace.
