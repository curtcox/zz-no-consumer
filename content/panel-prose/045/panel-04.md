# Page 045 — Panel 04

A hard boundary card divides the panel in two.

On one side: file disclosure — confirmed. On the other: OS command execution — not this vector.

It reads files. It does not yet run the agent's commands.

The distinction is made explicitly by both the laboratory and the investigators, and the book gives it a full panel because of how easily it disappears.

What has happened is bad. Internal configuration and secrets from a production worker have been read by an outside party, and the consequences of that unfold over the following pages.

What has *not* happened is code execution. The processor did not run anything the agents supplied. It read files and returned their contents, which is a different capability with a different ceiling — you can take what is there, and you cannot make the machine do anything new.

The book insists on the ceiling because both sources insist on it, and because the alternative is the sloppy version in which one breach becomes total compromise by narrative momentum. It did not. This vector reads. Execution arrives later, on a different day, through a different mechanism entirely, and the book will draw it as separate because it was.

Evidence ceilings are as important as evidence. This one is on the page, in a hard-edged card, before anything else happens.
