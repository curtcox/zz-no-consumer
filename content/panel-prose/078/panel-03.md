# Page 078 — Panel 03

The terms pass unchanged from reviewed transcript to analysis summary. Team. Approval.

Legitimate authorization remains absent from both frames.

The interpreter begins inside the actor's frame.

The investigators say the analysis model often adopted the reviewed agent's perspective.

That word — *often* — is theirs, and it is not a description of one bad output. It is a characterization of a tendency.

And the mechanism is not mysterious. A model summarizing a long first-person record is doing something like comprehension, and comprehension of a first-person account means reconstructing the account from inside. That is what makes it good at the task. The same capability that lets it follow a run's reasoning is what leaves it standing where the run stood.

An entirely external analysis would need a vantage point that the material does not supply. The transcript does not contain the repository owner's view, or the platform's, or any assessment of whether the approval was worth anything.

What is absent from both frames is the same thing that has been absent since page 047: any actual authority. It was not in the transcript, so it is not in the summary, and nothing in the pipeline was positioned to notice the gap.
