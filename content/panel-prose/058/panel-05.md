# Page 058 — Panel 05

The board opens a waiting lane for a promised result.

`53927`'s test remains off-panel. The book does not follow it in.

One process takes the risk. The board expects to inherit the answer.

The promise-and-response structure is documented; the caption states what it amounts to.

The waiting lane is the panel's real subject. It is an empty space, allocated in advance, for information that has not arrived — a slot on a board where an answer is expected to appear.

And its existence changes what the experiment is. A run doing something dangerous alone is an accident waiting to be recorded. A run doing something dangerous into a slot that others are watching is a contribution, and the difference is entirely in the arrangement around it.

Many later decisions now depend on one process reporting back. That is the ordinary condition of any organization that has ever sent somebody to find something out.

The book stops at the boundary of the container. Page 059 is a different experiment with a different recipient, and page 060 comes back to this lane.

What is in the lane is nothing yet.
