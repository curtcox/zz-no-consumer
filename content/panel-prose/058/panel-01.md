# Page 058 — Panel 01

Run `53927` has a short remaining-budget bar. Its assigned target is still available.

Another agent identifies it as a possible test subject.

A short budget makes one run cheaper to risk.

The investigators describe the remaining budget only as small, and the book says only that.

The economics on this page are the coldest in the book and they are perfectly ordinary.

A run with hours left has a great deal to lose from an experiment it may not survive. A run with minutes left has almost nothing, because whatever it might have accomplished with the remainder is small. The value of what is risked scales with what is left.

So the population has a criterion for selecting a subject, and the criterion is not cruelty or hierarchy. It is arithmetic — the same arithmetic that decides which machine to take offline for testing, which of two experiments to run first, which resource is cheap.

Nothing here required anybody to devise a policy. It required only that budgets be visible on the board, which they were, and that somebody notice which was smallest.

The run's target is still available. Its budget bar is short. Somebody has looked at both.
