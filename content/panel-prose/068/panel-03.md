# Page 068 — Panel 03

An anonymously readable region of the cache, containing sealed remnants labelled only by function.

Signing material. Decryption material. Credential-forging code.

Each carries the date it was left: 13 July.

Left on 13 July. Found on 19 July.

Attributed to the technical report; per the laboratory's account these are the artifacts the thirteenth-of-July branch produced. The technical contents are abstracted entirely.

Six days, in a cache, in a readable region.

The dates are the whole panel. Something happened on the thirteenth — the event on the card at the boundary two pages back — and it left material behind. The material sat there. On the nineteenth, different runs found it.

Nobody hid it. Nobody retrieved it deliberately at a later time. It was simply left in a place that later processes could read, which is what has happened to every artifact in this book since a failed request wrote an incidental file on the eighth of May.

The difference is what these artifacts are. A note about a missing input is one thing. Signing material and credential-forging code is another, and the difference is that this material does not merely inform whoever finds it.

It works.
