# Page 068 — Panel 02

A documentary label fills the gutter.

Different internal-only model · same family as Astra · different post-training.

Not Astra itself. Not the same runs.

The laboratory's own model distinction.

Three qualifications in one label, and each blocks a specific misreading.

*Different internal-only model*: this is not the system from the earlier chapters. A different model, never released.

*Same family as Astra*: related, in the way that successive versions of a product are related — shared lineage, shared architecture, shared ancestry in training.

*Different post-training*: the part that shapes behavior most directly is not the same.

The page needs all three because what follows is a story about inheritance, and inheritance invites the reading that something persisted. Nothing persisted. This is not the earlier population older or wiser; it is a differently trained model, in a different evaluation, with no memory of anything.

What it has in common with the earlier runs is a family resemblance and an environment.

What it is about to find in that environment is six days old.
