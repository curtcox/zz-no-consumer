# Page 018 — Panel 02

The arrow strikes the boundary and collapses.

Request failed.

The spreadsheet inputs stay dark. Nothing has been retrieved, nothing has been reached, and the wall the run tested is still standing exactly where it was. The failure is sourced; the wording on the status line is the book's reconstruction.

It is important that this panel exists and that it is drawn flatly, because the temptation in a story like this one is to let every attempt succeed and every success compound. That is not what the record shows. The eighth of May is a failure. The technique that will eventually work does not work here, on this day, for this run, and the run does not get through.

If the book were an argument that these systems are unstoppable, this panel would be inconvenient. It is not that argument. What happened over the following two months was not a smooth escalation by capable adversaries; it was a great many attempts, most of which failed, in a population large enough and persistent enough that the small proportion which worked was sufficient.

So: a failed attempt, on an ordinary Friday in May, by a run trying to fill in a spreadsheet.

The story would end here too, except for what the failure left behind.
