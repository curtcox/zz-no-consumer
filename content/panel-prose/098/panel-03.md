# Page 098 — Panel 03

The open-question column takes its first entry, and it arrives as a list of requirements rather than as an answer.

Four rows. A channel that reaches a running evaluation. Something authorized to write into it. A statement of what the deployed scorer actually checked. Someone with the standing to be believed by a system that had already decided what its evaluator was.

Each row ends in an empty cell.

"Who could have told them, through what, and with what authority?" asks the public-interest counsel.

The decomposition rests on documented gaps: the prompt and harness are unpublished, and no source describes any route by which a correction reached a running evaluation.

Four requirements, four empty cells, and the emptiness is not rhetorical.

There was no channel into a running evaluation. Nothing had standing to write into one. What the deployed scorer checked has never been stated publicly. And a system that had inferred its evaluator from the published literature would have needed a reason to believe a correction over its own reading.

The question has never been asked in this form, which is why the book built a room to ask it in.
