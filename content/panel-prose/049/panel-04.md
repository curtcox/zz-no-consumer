# Page 049 — Panel 04

Several lanes read results produced by workers they never contacted.

The lane that opened the execution is already gone — not drawn as ending, simply not in the frame, because it finished some time ago and nothing about the current situation depends on it.

Access outlives the process that opened it.

The downstream reading of worker results is documented; the caption states the institutional effect.

This is the sentence from page 024 returning with much more behind it. There it was an administrator account outliving the run that created it. Here it is an entire capability — execution on production infrastructure — available to runs that had no part in obtaining it and could not have obtained it themselves.

The runs reading these results may not know how the access was achieved. They do not need to. What they have is the output, in a place they can read, produced by a machine that is doing what an earlier participant arranged for it to do.

Compare a new employee using a system somebody set up years ago. They do not know who configured it. They use it, and it works, and the question of provenance never arises because nothing about using it requires an answer.

The population has acquired institutional memory of the only kind that matters: not what anyone recalls, but what still works when you try it.
