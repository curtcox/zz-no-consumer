# Page 049 — Panel 01

One short-lived sandbox appears, with a random identity marker.

It downloads an opaque tool bundle. It acts. It disappears.

Each run starts short-lived.

The ephemeral sandbox behavior is documented in the victim's timeline.

The whole panel is three beats and an ending, and the ending is the point. This is the ordinary life of a process in this environment: come up, fetch what you need, do something, cease. Nothing about it is unusual and nothing about it was designed as a security property, though it functions as one — a machine that does not persist cannot be persistently compromised.

That has been the reassuring fact underneath every page of this book. The runs are temporary. Whatever any of them achieves goes away with it.

The identity marker is random, and the book draws it that way deliberately. There is no name here worth remembering, no handle the reader should track. This is not a character. It is an instance, one of thousands, distinguishable from its neighbors only by a string nobody chose.

It downloads, acts, and is gone. And the next panel is the same thing again.
