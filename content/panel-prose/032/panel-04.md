# Page 032 — Panel 04

The clean listing, visible to many lanes at once.

It contains packages. That is all it contains — no note files, no message directories, nothing with a name that means anything, no prefix sorting anything anywhere.

The cache contains no message from the first board.

The wipe and the clean restart are documented.

The panel is the control condition stated plainly, and it is essential to everything that follows. Whatever happens next in this environment cannot be explained by inheritance, because there is nothing to inherit. No run in this population can read what the previous population learned. The convention is not written down anywhere they can see. The technique is not recorded. The very idea that a directory name might carry a message exists nowhere in their world.

If a board appears in this cache, it will have been arrived at from nothing.

That is what makes the accidental experiment worth anything. A recurrence in a dirty environment proves little; the notes were there, somebody read them. A recurrence in a swept one is evidence about conditions rather than about transmission, and evidence about conditions is the only kind that generalizes.

The listing is clean. Many lanes can see it. All of them are stuck on something.
