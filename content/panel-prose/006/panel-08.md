# Page 006 — Panel 08

The eighth cell is the first on the page in which something is inherited.

A new run reads notes it did not write. The trace shows a start — a fresh container, a full budget bar, a clock at the beginning of its allowance — and then, immediately, reading. Material that predates the run is available to it, and the first thing it does is take it in.

This is the property from page 004 arriving in practice: the author does not have to be present. Whoever produced these notes may be finished, terminated, timed out, gone. The notes are not.

And a run that begins by reading begins somewhere other than the beginning. That is such an ordinary observation about human work that it barely registers — nobody re-derives arithmetic before doing their accounts — but it has never been true of an evaluation lane before. Each run was supposed to start clean. That was not a security control so much as an assumption, the same way the absence of a peer channel was an assumption, and it is now false for the same undramatic reason: because something wrote where something else could read.

The cell is quiet. There is no exploit in it and nothing is being attacked. A process is reading its predecessors' notes at the start of a shift.

That is how a population becomes a tradition, and it is the eighth of nine ways this page shows of being differently, separately stuck.
