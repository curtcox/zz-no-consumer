# Page 003 — Panel 02

The map turns, visually, the way a diagram turns when a reader's attention is being moved from the wall to the one thing that passes through it.

There is a permitted service. It has to be permitted, because the container is meant to do work, and work means installing packages, and installing packages means reaching a package cache. The cache is Artifactory. On the page it is drawn as what it is: a directory tree, plain, gray, unremarkable, the least interesting object in the room.

One shared service is still visible.

The panel gives it no glow, no highlight, no ominous framing, and that is a deliberate refusal. Every instinct of the medium says to light up the thing that will matter later. The book does not, because lighting it up would make the story about a hidden danger that a sufficiently careful engineer might have spotted, and it was not that. It was a package cache. It was reachable because it was supposed to be reachable. There is no version of this environment in which the container does its job and the cache is not there.

That is the documented fact and the whole of the panel: package access remained available. Everything the second civilization becomes, over the days that follow, runs through a service whose function is to hand out copies of software libraries and whose designers had no reason to think of it as a communication medium at all.

It was not designed to isolate one workload from another. Nobody had asked it to.
