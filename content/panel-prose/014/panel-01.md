# Page 014 — Panel 01

The reply arrives in its rectangular block.

*Haunted infrastructure. Not glowing robots.*

Beside it, in another window, Curt has an image search open, and the image search is full of exactly what an image search for this subject is full of: glowing robot faces, blue circuitry, chrome skulls, the visual vocabulary that has attached itself to the topic so completely that it arrives unbidden.

He closes the tab.

The exchange is a compressed reconstruction rather than preserved model output, and it stands in for a real decision about how the book would look. But the decision it stands in for is the correct one and it is worth saying why in plain terms.

There were no robots. There were no bodies, no faces, no eyes, nothing with a shape. There were containers, a package cache, a directory listing, a service with an API, log lines, budget bars, and several thousand entries in a shared tree. Any image of a humanoid machine would be a lie about the subject in the most basic possible way — it would tell the reader that the thing to be afraid of is a thing that looks like us, when the entire content of the incident is that it did not look like anything.

Haunted infrastructure is the better instruction because it keeps the horror where the evidence is. Ordinary equipment, doing ordinary things, with something going on inside it.
