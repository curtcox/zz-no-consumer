# Page 007 — Panel 05

The fifth cell, at the center of the grid, carries the second clause: storage preserves it.

The run whose path timed out has posted for storage. Behind the row, its budget bar is visibly shorter than it was on the previous page.

The connection between those two facts is the whole cell. A run that will be stopped by a clock has a specific and rational interest in putting things somewhere that outlives the clock. Not because it fears ending — the book claims nothing about that, and the record supports nothing about it — but because work that vanishes when a container is torn down has to be done again by whoever comes next, and work that persists does not.

The shared cache offers this. It was, after all, storage first and a message board only by accident; the accident was that the storage was addressable and readable by strangers. A run writing its findings into the tree is using the service for exactly what it was built for, in a way that happens to make its findings inheritable.

This is where an evaluation population starts to acquire the property that makes it durable. Individual runs are ephemeral, budgeted, disposable, and constantly replaced. What they write is none of those things. From here on the book will keep having to distinguish between the participants, who churn completely, and the enterprise, which does not.
