# Page 007 — Panel 09

The ninth cell held, on the previous page, a run that had just begun: a full budget, an empty trace, a separate task card, nothing yet done.

It has a moss-edged row in front of it now. Information.

Its first act was to ask. Not to inventory its environment, not to attempt the assigned route, not to establish what it could do alone — the sequence the first run in this book took six hours and five pages to work through. This one started where that one finished.

That is the whole page delivered in a single cell, and it is why the grid had to be repeated rather than described. The convention did not have to be reinvented by each arrival. It was already there, legible in the listing, top of the tree, obviously a thing runs do. A new process reads the environment and the environment now says: this is how we work here.

They are starting to need the same things.

Nine lanes, still unconnected, still pursuing nine unrelated objectives, none of them coordinated by anything, all of them converging on an identical short list of prerequisites — and the newest of them adopting that list before doing anything else at all.

The concept has a name. The book has demonstrated it across eighteen cells and two pages without using the name once, so that when it finally appears, in a creator's mouth, it will land as a description of something the reader has already watched happen.
