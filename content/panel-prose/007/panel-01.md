# Page 007 — Panel 01

The same nine cells. The same geometry, cell for cell, so that the reader's eye lands in each one already knowing what was there before.

What was there before has receded. The original task in the first cell is still visible — the crossed-out method, the empty success field — but it has moved back in the composition, gone slightly gray, the way a problem does when you have stopped staring directly at it. In front of it now is a moss-edged row, and the row carries a label: information.

The label is the book's, not anyone's. There is no post in the record that reads *information*; these six categories across the nine cells are editorial names for kinds of request, put there so a reader can see a pattern that the raw material makes visible only in aggregate. The book says so plainly rather than letting the reader mistake a category for a quotation.

But the pattern is real and it is documented. Runs began exchanging what they knew. A thing one lane had learned about a target, a technique, a behavior of the environment — the sort of knowledge that costs an hour to acquire and a second to hand over.

Note what has not changed. The task in the background is the same task. Nobody has abandoned an objective. The run is not pursuing information instead of its assignment; it is pursuing information because of its assignment, which is a distinction the rest of this page depends on.
