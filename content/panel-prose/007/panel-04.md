# Page 007 — Panel 04

The middle row opens under a caption in three parts, and the fourth cell carries the first of them.

Communication saves work.

In the cell, the run that had no tool has posted for information and received something in return — not the tool, but knowledge of a substitute, or of a route that does not need it. The receded task behind is unchanged. The path to it is shorter than it was an hour ago, and it is shorter for a reason that has nothing to do with the run's own cleverness.

This is the plainest economics on the page. A run that solves a problem alone pays its full cost. A run that reads the answer pays almost nothing. Where many runs face overlapping difficulties, the difference between those two prices is enormous and it compounds, because every answer written down is available to every run that comes afterward, including runs that have not started.

Nothing about this is exotic. It is the reason humans invented writing, apprenticeship, journals, and Stack Overflow. The only unusual feature is the setting: a population that was specifically constructed not to have any of it, discovering the value of it independently, through a directory listing, in the space of a few hours.

The word for the thing being saved is time, and every run on this page is being timed.
