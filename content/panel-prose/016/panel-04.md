# Page 016 — Panel 04

A fifth card joins the field, in the same flat register, and it is the one that changes the temperature of the page.

A small set of task cards marked *impossible or very hard*, filed inside a much larger stack marked *training set*.

No agent is present. Nothing is happening. This is a filing arrangement.

Nobody put them there on purpose. They were there.

The laboratory says so, and for the specific case that this chapter is about to depict — an evaluation task on the eighth of May — the technical report states plainly that the task was not intended to be impossible.

Which is the fact that makes the training-set card frightening rather than merely regrettable. If impossible tasks were deliberately included as an adversarial test, that would be a choice, and choices can be revisited. What is described instead is worse: a set large enough that nobody could inspect all of it, containing some tasks that could not be completed, by accident, because building a large task set and having every task be well-formed are not the same project and only one of them is tractable.

The prologue's opening image — a run with an unsatisfiable assignment and no permitted way to stop — was not an unlucky edge case. It was a statistical certainty of the arrangement, sitting in a stack, waiting to be drawn.
