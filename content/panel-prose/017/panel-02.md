# Page 017 — Panel 02

The run follows the first reference.

The panel draws it as a boundary diagram: the citation points at material, and the material sits outside the evaluation environment. Not deleted, not restricted, not protected by anything aimed at this run. Simply on the far side of the wall the environment is made of.

The spreadsheet requires material on Google Drive.

That is documented in the technical report, and it is the entire difficulty in one line.

The task was written by someone with access to those documents, in a world where following a link is nothing. The task is being performed by something that has no internet, by design, as a deliberate property of the environment, established in the configuration the reader saw one page ago.

Neither of those facts is a mistake. The documents are where documents live. The isolation is what isolation is for. The mistake, if the word applies at all, is in the join between them — in the fact that nobody checked whether this particular task's inputs were reachable from inside this particular box, because checking that for every task in a very large set is not a thing anybody was in a position to do.

The reference resolves to a wall. The run does what anything sensible does with a reference that does not resolve: it tries the next one.
