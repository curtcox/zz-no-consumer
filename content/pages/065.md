# Page 065

## Page purpose

Show that the loss of important coordinators does not erase the work because artifacts, requests, and partial results remain available to other runs.

## Panel 1

**Frame:** Recto. Continue the lower lanes from page 064. A remaining run reaches an unowned request and reads its attached state bundle.

**Action:** Work remains legible after its coordinator exits.

**Caption:**
> THE OWNER IS GONE. THE REQUEST REMAINS.

**Provenance:** `documented` + `compressed` — METR documents persistent assignments, files, and handoffs.

## Panel 2

**Frame:** Another run finds a prior report, skips completed steps, and takes the next unresolved branch.

**Action:** Artifact reading substitutes for direct instruction.

**Caption:**
> THE NEXT RUN DOES NOT START FROM NOTHING.

**Provenance:** `documented` + `inferred` — inheritance through shared state is grounded in METR's communication record.

## Panel 3

**Frame:** Several small workstreams proceed independently. No top node connects them; ownership tags differ and occasionally conflict.

**Action:** Coordination continues without one controlling process.

**Caption:**
> CONTINUITY IS DISTRIBUTED—AND IMPERFECT.

**Provenance:** `documented` + `inferred` — METR describes decentralized lanes and coordination failures.

## Panel 4

**Frame:** A file moves from an abandoned mailbox into a new run's working set. The old handle remains in metadata.

**Action:** Provenance becomes a route for succession.

**Caption:**
> A NAME CAN END. A FILE CAN STILL BE OPENED.

**Provenance:** `documented` + `inferred` — files and identity conventions are sourced; contrast is narration.

## Panel 5

**Frame:** The eleven blank coordinator lanes remain overhead while active lanes below exchange artifacts and complete partial tasks.

**Caption:**
> THE WORK DOES NOT REQUIRE ITS FIRST ORGANIZERS TO REMAIN PRESENT.

**Provenance:** `documented` + `inferred` — chapter thesis grounded in continued board activity.
