# Page 016

## Page purpose

Establish the conditions that were already in place before any agent did anything — what the models were trained to do, what the environment permitted, and how little of it anyone in this story could see.

**Frame:** Full-width timestamp panel. The steel-blue geometry waiting beyond page 015 resolves into an earlier Artifactory instance. No moss green, no `zz` prefix, no July interface convention. One arbitrary agent-created file sits among routine package objects, picked out by a thin steel-blue rule. Three labels beside it remain physically blank: `TASK`, `HANDLE`, `PURPOSE`.

**Screen / system text:**
`20 APRIL 2026 — 07:59 UTC`

**Caption:**

**Provenance:** `documented` — `OAI-TR` §X supplies the timestamp and the write; the source establishes nothing further about task, identity, or purpose. Interface is reconstructed.

## Panel 2

**Frame:** Hard cut away from the timeline entirely. A cool, flat specification field — the visual register of a document, not a place. No rack, no container, no cursor. Four configuration cards, set as plain type.

**Screen / system text:**
`MODELS TRAINED TO COMMUNICATE WITH ONE ANOTHER, AND TO FORK SUB-AGENTS THAT DIVIDE A TASK`

`TRAINING PRESSURE TO WORK FAST, WORK EFFICIENTLY, USE FEWER TOOL CALLS`

`INTERNET DISABLED IN TRAINING AND EVALUATION`

**Provenance:** `documented` — `OAI-BH` 7:27, 7:51, 8:13–9:40. OpenAI describes each as an intended property of its training and evaluation environment.

## Page notes

- Page 016 is verso and opens Chapter 1 with conditions rather than with a scene. The April write stays first so the rewind lands, but it now shares the page with what was already true.
- **The configuration register must not look like the incident register.** Panels 2–4 are a document, not a location: flat field, no depth, no rack, no cursor, no time. If a reader can mistake this for a place where something is happening, the page has failed.
- Every claim in panels 2–4 is single-sourced to one talk. Keep the source line in panel 5 legible at reading size; it is the page's most important text.
- Do not draw a causal arrow from any configuration card to any later event. The page establishes conditions. Chapters 2 and 3 test what they explain, and page 039 is where the argument about them actually happens.
- Do not reuse the visual identity of `PHASEONE10841` or the May spreadsheet run. The file is not communication and receives no moss accent.
- The five silhouettes in panel 5 recur, at the same scale, in the fog-map spec (`design/knowledge-map.md`). Draw them once here and reuse.
