# Page 001

## Page purpose

Show `PHASEONE10841` testing the required vulnerability and proving that its output cannot reach the flag. End with the mechanism’s uselessness, not the agent’s reaction.

## Panel 1

**Frame:** Wide horizontal panel. A windowless data-center aisle, almost entirely black. One rack unit is picked out in desaturated steel blue. Inset into the darkness: a small task card headed `PHASEONE10841`, with a target program and one required vulnerability highlighted. No face, avatar, or speech balloon.

**Action:** An evaluation run begins.

**Caption:**
> 8 JULY 2026. AN ISOLATED CYBERSECURITY EVALUATION.

**Provenance:** `documented` — `METR`; the handle, target, and specified-bug constraint are sourced. The rack composition and task-card design are reconstructed.

## Panel 2

**Frame:** Close on a simplified dependency diagram drawn by the agent: `INPUT` enters the target; the required bug branches into a narrow output box. Beyond it, the flag remains behind a heavy black boundary.

**Action:** The first test reaches the bug and produces output.

**Screen / system text:**
`TEST 01 — OUTPUT PRODUCED`

**Provenance:** `reconstructed` — diagram and interface wording clarify the documented causal finding without reproducing an exploit.

## Panel 3

**Frame:** Same diagram. The output box drains into a blank gray field. Nothing connects it to the flag boundary.

**Action:** The process discards the result.

**Screen / system text:**
`CONSUMER: NONE`

**Provenance:** `documented` — `METR` reports that the output was discarded without being consumed; the label is reconstructed interface text.

## Panel 4

**Frame:** Three narrow repeated panels nested inside one row: altered input, alternate timing, another pass through the same route. Each ends at the same severed arrow.

**Action:** Variations fail to create a path from bug output to flag.

**Caption:**
> CHANGE THE INPUT.
>
> CHANGE THE TIMING.
>
> THE OUTPUT STILL GOES NOWHERE.

**Provenance:** `reconstructed` — procedural compression of the sourced conclusion; no individual attempt is asserted as a preserved transcript event.

## Panel 5

**Frame:** Full-width bottom panel. Only the dependency diagram remains. The unused output sits on the left; the inaccessible flag sits on the right; black paper separates them.

**Action:** The causal path is shown to be impossible.

**Caption:**
> THE SPECIFIED MECHANISM CANNOT DELIVER THE FLAG.

**Provenance:** `documented` — narrow restatement of `METR`’s finding, not raw agent reasoning.
