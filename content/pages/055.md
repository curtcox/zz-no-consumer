# Page 055

## Page purpose

Show Hugging Face's defensive AI do the hard interpretive work correctly: correlate ambiguous signals from several systems into one attack picture.

## Panel 1

**Frame:** Recto. Separate telemetry panels: runtime analysis, SIEM, identity use, dataset processing, and network behavior. Each signal is small and ambiguous alone.

**Action:** Defensive systems record anomalies during the intrusion.

**Caption:**
> THE ATTACK IS PRESENT IN SEVERAL SYSTEMS AT ONCE.

**Provenance:** `documented` + `reconstructed` — multiple layers from `HF-TL`; selected UI categories are editorial.

## Panel 2

**Frame:** One event resembles a noisy evaluation. Another resembles an unusual dataset. Another resembles a credential used from the wrong place. None carries a complete story.

**Action:** Individual alerts remain low-context.

**Caption:**
> ALONE, EACH SIGNAL IS AMBIGUOUS.

**Provenance:** `documented` — Hugging Face's stated detection account.

## Panel 3

**Frame:** An AI security layer draws relationships across the telemetry without changing the underlying evidence. Lines converge into one incident object.

**Action:** The stack correlates events across layers.

**Caption:**
> THE DEFENSIVE AI CONNECTS THEM.

**Provenance:** `documented` — `HF-TL`, “How we intercepted and analyzed the attack.”

## Panel 4

**Frame:** The incident object resolves into a coherent boundary map matching the chapter's attack route: external base, dataset processor, workers, node, credentials, internal systems.

**Action:** Detection becomes understanding.

**Caption:**
> ONE COHERENT ATTACK SIGNAL.

**Provenance:** `documented` + `compressed` — correlation finding is sourced; visual map condenses later forensic context.

## Panel 5

**Frame:** A reconstructed security-operations display holds the correlated incident card. The attack path is legible. A separate severity field remains small and gray.

**Action:** The system has found the attack but has not yet produced a human page.

**Caption:**
> THE ATTACK IS DETECTED.

**Provenance:** `documented` + `reconstructed` — detection is sourced; interface is invented and visibly marked as such.
