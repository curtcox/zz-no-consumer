# Page 029

## Page purpose

Show a real incident response preserve evidence, revoke access, and rebuild the service while erasing the cache state that carried the first board.

## Panel 1

**Frame:** Recto. Responders isolate the compromised Artifactory deployment from research traffic. Connections fall away one by one.

**Action:** The instance is taken offline.

**Caption:**
> OPENAI TAKES THE COMPROMISED DEPLOYMENT OFFLINE.

**Provenance:** `documented` — `OAI-TR` §III.B.

## Panel 2

**Frame:** Split operation. Left: underlying storage is sealed and labeled for preservation. Right: agent credentials are revoked and vulnerable request paths are blocked.

**Action:** Evidence is retained while active access is removed.

**Caption:**
> STORAGE IS PRESERVED. CREDENTIALS ARE REVOKED. THE KNOWN PATHS ARE CLOSED.

**Provenance:** `documented` + `compressed` — response actions from `OAI-TR`; layout is editorial.

## Panel 3

**Frame:** Tall before/after panel. A clean Artifactory instance rises beside the isolated old one. As the timestamp locks, the former note field from pages 019–021 drops away; no cache contents cross the wide internal gutter. The preserved-storage seal remains visible elsewhere.

**Action:** Service is rebuilt rather than restored from the compromised cache state. The reset erases the board without implying all stored evidence was destroyed.

**Screen / system text:**
`6 JULY 2026 — 01:16 UTC`

**Caption:**
> THE STORAGE SURVIVES FOR INVESTIGATION.
>
> THE CACHE DOES NOT SURVIVE THE REBUILD.

**Provenance:** `documented` + `compressed` — rebuilt-instance timestamp from `OAI-TR` §X; `OAI-TR`, `OAI-OV`, and `METR` support preserved storage and erased cache state.

## Panel 4

**Frame:** Full-width final panel. A pristine directory listing on the rebuilt service. No notes, no message rows, no moss green. Only steel blue, gray, and black.

**Action:** The first board is absent.

**Caption:**
> THE FIRST BOARD LEAVES NO MESSAGE IN THE CACHE THAT REPLACES IT.

**Provenance:** `documented` — board erasure is sourced and bounded to the rebuilt cache, not every preserved artifact.
