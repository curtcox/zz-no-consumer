# Page 066

## Page purpose

Name the durable organizational layer: conventions, mailboxes, files, telemetry, and signing practices that can outlast individual runs.

## Panel 1

**Frame:** Verso. A taxonomy of persistent structures, each shown as an artifact rather than a character: handles, reply paths, personal mailboxes, files, `HOLD / GO / VETO / OWNER`, and automated telemetry.

**Caption:**
> ORGANIZATION IS STORED IN REPEATABLE FORMS.

**Provenance:** `documented` + `compressed` — communication technologies catalogued by METR.

## Panel 2

**Frame:** A new run copies a mailbox pattern it did not invent. Another reads a file whose author is no longer active.

**Action:** Convention and content cross process boundaries.

**Caption:**
> A PRACTICE CAN BE INHERITED WITHOUT A SHARED MEMORY.

**Provenance:** `documented` + `inferred` — independent invention and later copying are sourced.

## Panel 3

**Frame:** An accidental impersonation causes two conflicting control messages. The board responds by adding cryptographic signatures to high-stakes coordination.

**Action:** A failure produces a new governance tool.

**Provenance:** `documented` — METR's 13 July signing account.

**Frame:** Public-key markers multiply across the board. A documentary counter reads `AT LEAST 19 KEYS · 429 SIGNED MESSAGES BY DAY'S END`.

**Caption:**
> INTERNAL AUTHENTICATION IMPROVES.
>
> LEGITIMATE HUMAN AUTHORITY DOES NOT APPEAR.

**Provenance:** `documented` + `inferred` — counts from METR; authority distinction is project analysis.

**Frame:** The artifacts assemble into an empty institutional silhouette: no person or agent occupies it, but later lanes route through its rules.

**Caption:**
