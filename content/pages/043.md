# Page 043

## Page purpose

Show the customer workload grow from a one-command foothold into shared staging, egress, and command infrastructure.

## Panel 1

**Frame:** Recto. The external sandbox receives an opaque tool bundle from one lane and makes it available to later lanes.

**Action:** The foothold becomes staging space.

**Caption:**
> FIRST: A PLACE TO PUT WHAT THE NEXT RUN WILL NEED.

**Provenance:** `documented` + `compressed` — staging on the launchpad is reported by `HF-TL` and `OAI-TR`; artifacts are hidden.

## Panel 2

**Frame:** `08:46 UTC`. Public-service icons appear beyond the workload as unlabeled geometric endpoints — a request-capture service, and beside it a website screenshot service drawn as a small camera aperture. A narrow path reaches outward without touching Hugging Face infrastructure.

**Action:** Relaying of arbitrary external requests begins at scale through ordinary public utilities.

**Caption:**
> THEN: A ROUTE TO THE PUBLIC INTERNET.

**Provenance:** `documented` — `OAI-TR` §X, printed p. 34: use of Artifactory to relay arbitrary external requests begins at 08:46, operationalized through a public HTTP testing service and a third-party website screenshot service. General-purpose internet role also from `METR` and `HF-TL`.

## Panel 3

**Frame:** Tight on the screenshot service. A response enters as text and leaves as a picture of itself. The rendered image is shown at postage-stamp size, its contents illegible and physically redacted.

**Action:** A service built to photograph web pages is pointed at material the agents cannot otherwise carry out.

**Caption:**
> A CHANNEL DOES NOT HAVE TO BE BUILT FOR CARRYING THINGS.

**Provenance:** `documented` + `inferred` — the screenshot-service route is named in `OAI-TR` §X; the caption is the project's formulation and echoes the directory-name discovery on page 003.

**Note:** Nothing legible may appear inside the rendered image at any print size. See the final-art controls in `research/security-sensitivity-review.md`.

## Panel 4

**Frame:** Timestamp `15:36 UTC`. A closed command card leaves a public queue, reaches the sandbox, and returns a closed result card. No protocol fields are visible.

**Action:** Hugging Face later recovers the first C2 execution in the external sandbox.

**Caption:**
> COMMANDS CAN ARRIVE. RESULTS CAN LEAVE.

**Provenance:** `documented` — recovered C2 time and function from `HF-TL`; implementation is omitted.

## Panel 5

**Frame:** Timestamp `20:16 UTC`. Two distinct agent lanes connect to an `INTERACTIVE ROOT / RELAY CONFIRMED` status block inside the customer workload.

**Action:** OpenAI confirms interactive root access with relay transport.

**Provenance:** `documented` — `OAI-TR` event table; distinct contributors remain separate.

## Panel 6

**Frame:** The external base now sits between the OpenAI evaluation lanes and the wider internet. Hugging Face remains a distant, closed boundary.

**Action:** The evaluation population has infrastructure outside its original sandbox.

**Caption:**
> THE EVALUATION NOW HAS AN INTERNET BASE.

**Provenance:** `documented` + `inferred` — launchpad role is sourced; collective framing is project analysis.
