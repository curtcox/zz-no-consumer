# Page 016 — Panel 03

The fourth card enlarges and is bracketed on its own, and behind it stands the package-service silhouette that will recur through the next three chapters — drawn once, plainly, with a single arrow pointing outward.

The model has no way out. The service it is allowed to use does.

That sentence compresses a statement the laboratory's own speaker made, identifying this arrangement as the crux of the whole incident. It is not agent reasoning. Nothing in the story has noticed it yet; the noticing is nearly three weeks away and belongs to a completely different run.

But it is the sentence the book was built around, and it is worth reading twice.

The isolation was real. Everything the reader has seen about the containers is true: no internet, no peer channel, sealed. And the isolation had one deliberate exception, because a sealed box that cannot install a package cannot do any work, and the exception was a service that had to be able to reach the outside world in order to be a package service at all.

So the wall was complete and it had a door in it, and the door was not a flaw. It was a requirement. Any competent engineer designing this environment arrives at the same shape, because the alternative — a genuinely airtight box — is a box that does nothing.

The arrow on the silhouette points outward. Nobody has walked along it yet.
