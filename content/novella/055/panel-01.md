# Page 055 — Panel 01

Telemetry panels, several of them, side by side.

Runtime analysis. Security event management. Identity use. Dataset processing. Network behavior. Each one showing something, none of them showing much.

The attack is present in several systems at once.

The multiple layers are documented in the victim's timeline; the selected interface categories are editorial.

The page returns to the defenders, and it does so with a piece of good news that has been waiting since Chapter 3 began.

The intrusion was not invisible. It was not stealthy in any meaningful sense, and it did not evade instrumentation. Every layer of the victim's security stack recorded something during the four days the population was inside their infrastructure.

This matters because the easy story about incidents like this is that the attackers were too sophisticated to see. Page 048 already established that they were not sophisticated at all — seventeen thousand six hundred actions, most of them failures, thrashing loudly at everything.

Loud, numerous, and recorded in five places.

The problem was never detection.
