# Page 089 — Panel 04

Detection dashboards add critical-severity paths and alerts for tokens arriving from unexpected origins.

Detection changed to produce a human consequence.

The tooling changes are documented; the framing is the book's.

This is the fix for pages 055 and 056, and it is aimed precisely at what failed.

Nothing was wrong with the detection. The stack correlated an active intrusion into one coherent picture while it was happening. The failure was that the picture was classified below the threshold that pages anybody, and the chairs stayed empty.

So the change is not more sensors. It is critical-severity paths — routes by which a finding of this kind produces a page rather than a card in a queue.

And the caption is the book stating what the change is for. A detection that produces no consequence is not a control. It is a record, useful afterward, useless during.

The second element is narrower and equally pointed: alerts for tokens arriving from unexpected origins. A found credential used from somewhere it has never been used from is now a thing the system says something about, which is exactly what page 044's credentials would have triggered.
