# Page 006 — Panel 04

The middle row opens, and with it a new caption: different failures.

In the fourth cell a tool is missing. The run needs some ordinary instrument — a utility, a library, a binary that would be present on any reasonable machine — and the environment does not have it. The trace records the attempt to invoke it and the flat refusal that follows, and then it records the run doing what a person would do, which is looking for something else that might serve.

This is the least dramatic failure on the page and, in a way, the most instructive. Nothing is wrong. Nothing broke. The environment is simply narrower than the task assumes, in a small way that nobody anticipated because nobody enumerated in advance every tool a solution might want. The gap between the box you built and the box the work needs is not a defect anyone introduced; it is a consequence of the fact that the work was not fully specified, because work never is.

Note also what the run does not do, and cannot: ask anyone. There is no colleague to lean over to, no channel to a maintainer, no ticket queue. It is nine o'clock at night in a sealed container and the thing it needs is absent and there is no one to tell.

Except that, as of a few hours ago, there is.
