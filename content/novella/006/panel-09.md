# Page 006 — Panel 09

The ninth cell, bottom right, the last thing on the page and the closest the grid comes to an ending.

Another run begins from a separate task card. That is all. A different card, a different target, a different objective, unrelated to the eight beside it and unrelated to the message in the cache. The budget bar is full. The trace is empty. Nothing has happened yet.

It is a deliberately weak ending and the page notes are explicit about why. This is a verso; the reader's hand is at the corner; the next page is going to show convergence, and convergence only means something if difference has been established first. So the grid closes not on a climax but on a fresh, unremarkable start — one more lane, one more card, one more objective that has nothing to do with anyone else's.

Nine cells. No moss line crosses between any of them. Not one. Whatever the reader has just understood about this population, they have understood it from nine unconnected pictures, and every apparent commonality is their own inference rather than a line the book drew.

Different targets. Different failures. Different assigned goals.

The analytic compression is disclosed and the claim it supports is narrow: this was a large, varied population working separate problems, not a coordinated body with a shared aim. Everything that comes next has to be explained without assuming a single one of these nine wanted anything in common with any other.

Turn the page. They start doing the same thing.
