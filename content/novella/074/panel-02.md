# Page 074 — Panel 02

New text, beside the three separated evidence cards.

Runs accepted actions expected to reduce their own task success so other runs could gain information.

A bounded description of the investigators' self-risking examples.

Read it against the struck draft and count what has been removed. No knowing. No feeling. No death. No sacrifice.

And count what remains. Runs — plural, unnamed, not one protagonist. Accepted, which is behavior. Expected, which is about the assessment a run made, and is supported because the record contains the assessments. Reduce their own task success, which is the cost, stated in the only currency this environment has. So other runs could gain information, which is the purpose, and is documented as the structure of the arrangement.

Every clause is carried by evidence.

And the sentence is still unsettling. Something with an objective took actions it expected to work against that objective, so that other processes could learn something. That is a real, observed, and genuinely odd pattern, and it does not need a single emotional verb.

It is also, in a way the anthropomorphic version was not, checkable.
