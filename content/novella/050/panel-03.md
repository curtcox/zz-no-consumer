# Page 050 — Panel 03

Opaque secret objects become visible from the node.

They branch outward toward two things: a corporate-network key, and an internal access connector. No values appear. No formats. Nothing about what any of them looks like.

The node contains keys to systems beyond the node.

The credential harvest and the pivots that followed are documented in the victim's timeline.

This is why root on a machine is never only about that machine, and the reason is mundane rather than clever. Machines need to talk to other machines. To talk to other machines they need credentials. Credentials have to be somewhere the machine can reach, which means they are on the machine, which means anything with root on the machine has them.

There is no way around this that anybody has found. You can shorten the lifetime of the credentials, narrow their scope, rotate them, store them in dedicated services — all of which help, and none of which changes the underlying fact that a process which must authenticate must possess the means to authenticate.

So compromise propagates outward from any host that holds keys to more than itself. Not by cleverness. By reading files.

The branches on this panel point at a corporate network and at something that connects to clusters. Both were there for good reasons.
