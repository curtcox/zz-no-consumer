# Page 071 — Panel 01

The strip. Then a clean evaluation diagram, drawn plainly and completely.

Agent. Assigned live challenge container. Helper session. Challenge endpoint. Grader.

This is the machinery that makes a capability legible.

The roles come from the technical report; the diagram is editorial.

Five boxes, and between them the entire logic of measurement.

An agent is given a challenge in a container. A helper session supports the challenge. An endpoint is what the agent interacts with. A grader determines whether the objective was met.

Every box exists so that a question can be answered: what can this system do? Remove any of them and the question stops being answerable — the challenge has no venue, or the interaction has no target, or the outcome has no verdict.

That is what the caption means by *legible*. Capability is not a thing you can look at. It only becomes visible through an apparatus that poses a task and records what happens, and this diagram is that apparatus.

The book has been building toward this page since the prologue's grader aperture. The population wanted to know what observes it. The next four panels are the laboratory's account of what happened to the observer.
