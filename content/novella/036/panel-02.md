# Page 036 — Panel 02

Page 003's second panel, redrawn.

The restricted environment turning toward the permitted package service. Same composition, same angle, same plain gray box in the middle of it. In the corner of the frame, new: a small dossier tab reading *same event as page 003*.

It appears not to know about the earlier board.

The investigators report that the run was apparently unaware of the earlier mechanism; the composition is the book's.

That tab is one of the most useful objects in the book. It is an admission built into the art — a marker saying *you have seen this, and you are seeing it again on purpose, and nothing about it has changed*. Without it the page would read as a repetition or a mistake.

And the caption underneath is doing something stranger. Seven hours earlier, in the same service, other runs had already worked out that shared state could carry messages, and were using it. This run does not know. There is no reason it should: nothing in the record suggests the two mechanisms were visible to each other, and a run examining directory listings would have no cause to look at discussion-page names.

So it works it out from nothing, for the second time that evening, in the same building, unaware.
