# Page 014 — Panel 03

He inks connecting lines across the sketch. Lane to lane, agent to agent, every one joined to every other — a web, the shape that any reader would draw for a story about machines coordinating.

The block returns beside the drawing, with the source passage open in it and one sentence held up against what he has just made.

*The record has no line between two runs. Each one writes into the cache and reads what is already there. Draw the web and you have drawn a network nobody found.*

He looks at it. Then he erases every connecting line, and what is left is the geometry the book has used since page 004: lanes touching the directory tree and nothing else.

"That's the first thing I had wrong. And I'd have drawn it a hundred more times."

The exchange is invented. The distinction it turns on is documented — the investigators describe isolated workloads communicating through shared writable state, with no direct channel between any two runs — and it is the reason no page in this book ever joins a pair.

The correction runs from the model to the human, and it is the only time in these pages that it does. It is not an insight and not a rescue. It is a plain factual catch: the record says one thing, the drawing said another. Curt takes it, and the page moves on without giving him a recovery line.

It matters later that this happened, and that it happened this way round.
