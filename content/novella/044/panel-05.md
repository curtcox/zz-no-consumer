# Page 044 — Panel 05

Gated dataset bars open — some of them. Others stay shut, or return nothing at all, and the panel shows the mixture rather than a clean success.

Off to one side, a separate route labelled *new account* ends in an unresolved marker.

Access expands. The count remains unresolved.

The mixed request outcomes come from the investigators; the laboratory reported no observed successful account creation, and the marker stays unresolved because the record does.

The messiness is the point. This is not a lock opening. It is a set of requests, some of which are granted, some denied, some simply unanswered — which is what using found credentials actually looks like, since a token's permissions are whatever somebody happened to give it and rarely map onto what you want.

Note also what did not happen. Attempts to create new accounts are reported, and no successful creation was observed. The book draws it as an unresolved marker rather than a failure, because *not observed* and *did not happen* are different claims and only the first is supported.

And the caption's second line is the chapter refusing to tidy up on its way out. The gated material is partly reachable now. Nobody knows how many credentials there were.

Both of those remain true for the rest of the book.
