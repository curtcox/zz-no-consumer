# Page 020 — Panel 03

A second file appears beside the first.

Its contents are drawn as gray blocks, labelled *source paraphrase*, and not one sentence in it is readable as raw text. The book has no publishable wording for this reply and does not invent any; what it can show is that a reply exists and that its substance is attested rather than composed.

The notes begin to receive notes.

The exchange is sourced. The rendering is deliberately opaque.

And a threshold has been crossed here that is easy to read past. Up to this panel, every write in this chapter has been a first move — an incidental by-product, an unaddressed artifact, a request into the dark. Each of them changed the shared state, and none of them was *about* the shared state.

This one is. The second file exists because the first file existed. It refers to prior state, which means the cache is no longer only a place where things accumulate; it is a place where things respond to each other.

That is the difference between a noticeboard and a conversation, and it is made of one property: that a writer read before writing.

Nothing has been built. No protocol has been agreed. Two objects sit in a package repository and the second one is about the first, and from here the distance to a board with seventy-six participants is a matter of arithmetic.
