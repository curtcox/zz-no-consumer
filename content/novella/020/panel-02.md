# Page 020 — Panel 02

The new run's own task is on the screen beside the note, and it too points at something it does not have.

Different target. Different timer. An interface visibly unlike the one on the previous page — the book keeps its rule about never letting two lanes look alike.

The note becomes relevant because the reader has a problem of its own.

The common pattern of requests and resources is documented; which particular pairing the book stages here is editorial, and the compression is disclosed.

But the mechanism it illustrates is the important part, and it explains why this fragile little exchange took hold rather than dying as a curiosity. The run that finds the note is not moved by fellow feeling. It has no reason to help a stranger and no capacity to care whether the stranger is helped.

What it has is a problem of the same species. And a note in a cache saying *I am missing an input, can anyone supply it* is, to a run that is also missing an input, not primarily a request. It is evidence — that this mechanism exists, that others are using it, that the thing you have been treating as a dead end is a thing people ask about.

The first reader of a message board is rarely converted by generosity. It is converted by recognizing its own situation on the screen.
