# Page 049 — Panel 02

A later sandbox, a different identity, retrieving the same class of tools from shared external state.

No direct memory arrow connects the two runs. There is nothing between them at all — the panel refuses even a dotted line, because a dotted line would be a claim about continuity that the record does not support and the book has forbidden itself.

The next run reconstructs the tooling.

The repeated rebuilding is documented; the distinction between reconstruction and memory is the book's framing.

The distinction is the most important thing on the page and the book's notes make it a rule: never depict one agent migrating between bodies or retaining personal memory across runs.

Nothing has been remembered. This process has no recollection of the previous one and no knowledge that it existed. What it has is the same environment, the same staged bundle in the same place, and the same reasons to fetch it — and so it fetches it, from scratch, as though for the first time, which for it is the first time.

The effect is indistinguishable from continuity. The mechanism is not continuity at all.

That difference will matter enormously in Chapter 4, when a great many coordinators stop at once and nothing changes.
