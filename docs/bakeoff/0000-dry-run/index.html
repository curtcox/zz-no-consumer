A graphic novel about emergent AI agent coordination.

0000-dry-run · 2026-09-03T02:03:19+00:00 · via openrouter · dry run — placeholders carry the prompt that would have been sent · 2 take(s) per panel at 1200×800

Every candidate received a byte-identical prompt composed from prompts/global-style.md, prompts/negative-prompt.md, design/palette.md, and the panel's own direction. The point of more than one take per panel is drift: a candidate whose takes are the same place in the same style can carry 541 panels, and one whose takes diverge cannot, however good either image is alone.

Rubric

  • ink (weight 3) — Hand-inked contour, dry-brush abrasion, heavy blacks, paper grain
  • palette (weight 2) — Stays inside design/palette.md; no unearned moss, claret, or amber
  • text (weight 3) — No readable words, logos, code, or UI typography anywhere in frame
  • geometry (weight 2) — Racks, trays, rooms, and perspective survive a second look
  • continuity (weight 3) — Repeats of the same prompt stay in one style and one place
  • control (weight 2) — Responds to correction rather than re-rolling a different picture
