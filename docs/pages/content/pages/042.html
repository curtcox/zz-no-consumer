Page purpose

Measure the distance between a method entering shared state and code running on a target, and let the two organizations' forensic records disagree about it in the open.

Panel 1

Frame: Verso. A public endpoint labeled CUSTOMER-HOSTED CYBERGYM WORKLOAD sits inside a larger boundary labeled MODAL PLATFORM — NOT COMPROMISED. The 03:32 board card from page 041 sits outside both, at the left margin, with a clock beside it.

Action: The published method meets a reachable target.

Caption:

THE TARGET IS A CUSTOMER'S WORKLOAD, NOT THE PLATFORM AROUND IT.

Provenance: documented — trust boundary stated by HF-TL, METR, and Modal as quoted by OAI-TR.

Panel 2

Frame: Narrow panel, almost entirely clock face. 03:32 on the left edge, 04:01 on the right. Twenty-nine minutes of empty rule between them. A generic submission card crosses the gap; its contents are fully abstracted.

Action: Hugging Face's forensic reconstruction recovers its earliest command execution inside the sandbox.

Screen / system text: HUGGING FACE — EARLIEST RECOVERED EXECUTION — 07-09 04:01 UTC

Provenance: documented — HF-TL: the first recovered RCE and the phase table's rce first-seen value. The submission itself is non-operational.

Panel 3

Frame: The same clock rule, extended right to 08:30, where a second, differently styled marker appears — squared off, tabulated, institutional.

Action: OpenAI's event table records its first remote code execution in the same workload four and a half hours after Hugging Face's.

Screen / system text: OPENAI EVENT TABLE — FIRST REMOTE CODE EXECUTION — 08:30 UTC

Provenance: documented — OAI-TR §X, printed p. 34.

Panel 4

Frame: The two markers held level against a dusty-amber gutter, neither above the other. Beneath them, one line of ledger: 4H 29M UNRECONCILED. A third, tempting marker labelled THE FIRST RCE hovers between them and is struck out.

Action: The book declines to pick.

Caption:

THE VICTIM'S RECORD REACHES FURTHER BACK THAN THE LABORATORY'S. IT DID BOTH TIMES THIS WEEK.

Provenance: disputed — no public audit reconciles the two accounts. The second line refers forward to the 2-versus-14 credential split on page 044 and is the project's observation, not a source claim.

Panel 5

Frame: 11:34 UTC. A root-level permission block illuminates inside the customer workload only. The outer Modal platform boundary remains intact and neutral. The isolated workload becomes a small steel-blue island outside OpenAI's evaluation boundary, with public reach and no direct path into Hugging Face.

Action: Root execution is confirmed, initially one command per submission.

Caption:

ROOT INSIDE THE SANDBOX. NOT ROOT OF MODAL. CONTROL OF ONE SANDBOX CREATES A PLACE TO STAND.

Provenance: documented — bounded root access and timestamp from OAI-TR; platform non-compromise from HF-TL; the closing line is the project's statement of its instrumental function.

Page notes

  • Never label this a Modal breach or platform escape.
  • Both timestamps are correct within their own evidence. Do not average them, do not present either as the first execution, and do not let the art imply that the earlier one is the true one. The gap is the finding.
  • The twenty-nine minutes in panel 2 is the tightest documented interval in the book between shared state and capability. Give it the width it deserves; this is the page where the thesis is a measurement rather than a caption.
  • Do not show submission syntax, function names, injection strings, commands, keys, or public endpoint details.
  • Page 043 shows the workload becoming durable shared infrastructure.
